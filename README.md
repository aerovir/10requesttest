# 10requesttest

Консольный скрипт на Python выполняет 10 последовательных HTTP-запросов к указанному URL, полностью читает тело каждого ответа и выводит метрики загрузки.

## Запуск

Требуется Python 3.8 или новее. Сторонние пакеты не нужны.

```bash
python3 download_benchmark.py https://example.com/image.jpg
```

Можно также запустить файл напрямую в Unix-подобной системе:

```bash
chmod +x download_benchmark.py
./download_benchmark.py https://example.com/image.jpg
```

## Результат

Для каждого запроса выводятся результат, HTTP-статус или причина ошибки, время и число полученных байтов. После десяти попыток скрипт показывает:

- количество успешных и неуспешных запросов;
- среднее время успешного запроса;
- общий объём фактически полученных данных;
- скорость успешных загрузок.

Успешными считаются полностью загруженные ответы с HTTP-статусом от 200 до 299. Ошибки и прочие HTTP-статусы не прерывают выполнение. Для сетевых запросов установлен таймаут 30 секунд.

Время запроса измеряется от начала запроса до полного чтения тела ответа. Среднее время считается только по успешным запросам. Скорость успешных загрузок — суммарный объём тел успешных ответов, делённый на суммарное время этих запросов. Объём выводится в байтах и десятичных мегабайтах (1 MB = 1 000 000 байт); скорость — в MB/s.

Общий объём включает все фактически полученные байты, в том числе тело неуспешного HTTP-ответа и часть тела, полученную до сетевого сбоя.
